설정

컴퓨터실은 31번 고정 좌석으로 배치됩니다. 일반교실은 입력한 열·행에 맞춰 한 칸에 한 자리씩 배치됩니다.
삭제할 반을 선택한 뒤 ‘선택한 반 삭제’를 누르면 해당 반의 좌석표, 특이사항, 색상, 출결, 진도 기록이 함께 삭제됩니다.

백업 / 가져오기

다른 컴퓨터에서 사용하려면 백업 파일을 내보낸 뒤 이곳에서 가져오면 됩니다.

GitHub 동기화 설정

💡 여러 기기 동기화 방법: 개인 GitHub 저장소에 데이터를 암호화하여 저장합니다. 학교, 집, 모바일 어디서나 실시간으로 동일한 자리배치도를 수정하고 확인하실 수 있습니다.
⚠️ 주의: 이 비밀번호는 데이터 복호화에 절대적으로 필요합니다. 분실 시 데이터를 복구할 수 없습니다. 공개 저장소를 사용 중이라면 반드시 비밀번호를 설정하여 개인정보를 보호하세요.
* GitHub 토큰 발급법: GitHub 로그인 > 우측 상단 프로필 > Settings > Developer settings > Personal access tokens > Tokens (classic) > Generate new token (classic) > repo 권한 선택 후 생성 > 발급된 키(ghp_...) 복사 붙여넣기

Google 스프레드시트 (Apps Script) 동기화

✨ 가장 편리하고 안전한 구글 시트 연동: 본인의 구글 스프레드시트와 연동하여 학교 PC, 태블릿, 모바일, 집 어디서든 데이터가 실시간으로 자동 저장되고 동기화됩니다. 토큰 발급 없이 Apps Script 웹 앱 URL만 넣으면 끝!
📌 3분 구글 시트 연동 초간단 순서:
1. 새 구글 스프레드시트 생성
2. 상단 메뉴 [확장 프로그램] > [Apps Script] 클릭
3. ‘📋 Apps Script 설정 가이드 및 코드 보기’ 버튼을 눌러 나오는 코드를 그대로 복사-붙여넣기
4. 우측 상단 [배포] > [새 배포] > 유형: [웹 앱] 선택 (액세스 권한: 모든 사용자(Anyone) 설정)
5. 발급된 웹 앱 URL을 위의 입력란에 붙여넣고 저장!

📋 Google Apps Script 설정 코드 및 연동 가이드

구글 스프레드시트의 [확장 프로그램] > [Apps Script]를 열고, 기본 코드를 모두 지운 뒤 아래의 코드를 전체 복사하여 붙여넣기하세요.

🚀 배포 단계 (매우 중요)

  1. Apps Script 에디터 우측 상단의 [배포] > [새 배포]를 클릭합니다.
  2. 왼쪽 톱니바퀴 아이콘을 눌러 유형으로 [웹 앱]을 선택합니다.
  3. 설정 항목을 다음과 같이 맞춥니다:
    • 설명: 교실 자리배치도 연동 (자유롭게 입력)
    • 다음 사용자로 실행: ‘나’ (내 계정)
    • 액세스 권한이 있는 사용자: ‘모든 사용자’ (Anyone) (※ 학교 계정이더라도 반드시 모든 사용자로 설정해야 브라우저에서 바로 연동됩니다.)
  4. [배포] 버튼 클릭 > 계정 액세스 승인 > 생성된 ‘웹 앱 URL (https://script.google.com/macros/s/.../exec)’을 복사하여 설정의 입력창에 붙여넣으면 완료!
