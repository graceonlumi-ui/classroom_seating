# 교실 자리 배치도 (Classroom Seating Arrangement)

중·고등학교 수업 환경(컴퓨터실 및 일반 교실)에서 학생들의 **자리 배치, 출결 관리, 실시간 과제 체크, 수업 진도, 시간표 연동, 수업 타이머, 학생 추첨, 모둠 구성**을 한 번에 할 수 있는 웹 애플리케이션입니다.

---

## ✨ 주요 기능

### 1. 🪑 교실 자리 배치 & 순서 제어
- **컴퓨터실 모드 (31번 고정)**: 분단 통로(좌 3석 / 우 4석)가 적용된 컴퓨터실 전용 레이아웃.
- **일반 교실 모드**: 행(가로)과 열(세로) 수를 자유롭게 설정 가능 (1~10칸).
- **상하·좌우 시점 뒤집기**: 교사 기준(앞에서 보기) 및 학생 기준(뒤에서 보기) 시점 전환.
- **번호순 / 번호 역순 재배치**: 1번부터 차례대로 배치하거나, 끝 번호부터 역순으로 원클릭 재배치 지원.
- **자리 무작위 섞기 (Shuffle)**: 학생들의 좌석을 한 번에 랜덤으로 섞어 새롭게 배치.
- **직관적인 1:1 자리 이동**: 이동 모드에서 클릭-클릭으로 손쉽게 좌석 교체.

### 2. 🎲 학생 발표자 / 당첨자 추첨기 (Lucky Draw)
- 질문, 발표, 실습 시범 학생을 1명~5명까지 무작위로 뽑기.
- 긴장감을 높여주는 룰렛 회전 애니메이션 & Web Audio API 기반 드럼롤/팡파르 효과음.
- 축하 컨페티(색종이) 파티클 애니메이션 및 당첨 이력 기록.
- 오늘 결석/조퇴생 자동 제외 옵션 지원.

### 3. ⏱️ 수업 활동 타이머 (Classroom Timer)
- 코딩 실습, 조별 토의, 퀴즈/시험 시 활용할 수 있는 카운트다운 타이머.
- 1분, 3분, 5분, 10분, 15분, 20분, 30분 빠른 프리셋 & +1분/+30초 빠른 추가.
- 자리배치도를 보며 사용할 수 있는 **미니 플로팅 타이머** & 전자칠판용 **전체화면(Fullscreen)** 모드 지원.
- 10초 이하 긴박한 시각적 펄스 효과 및 종료 시 맑은 차임벨 알림 사운드 재생.

### 4. 👥 지능형 모둠 구성기 (Group Formation)
- 모둠 개수 기준(예: 4모둠) 또는 모둠당 인원수 기준(예: 4명씩) 자동 분할.
- **배정 방식**:
  - `무작위 랜덤 배정`
  - `수준별 균등 밸런스 배정` (학생 정보의 우수/보통/부진/관찰 레벨을 각 조에 골고루 분배)
  - `출석번호 순서 배정`
- **좌석표 모둠 뱃지 연동**: 자리배치도 상에 모둠 번호 및 테마 색상 뱃지 표시.
- 모둠 명단 원클릭 클립보드 복사 지원.

### 5. 📋 출결 & 실시간 과제 체크
- **출결 관리**: 지각, 조퇴, 결과, 결석(질병/미인정/인정/기타) 및 출결 메모 기록, 출결 CSV 저장.
- **과제 제출 체크**: 좌석의 체크박스를 눌러 실시간 제출(1) / 미제출(0) 토글.
- **과제 현황 리포트**: 학생별/날짜별 누적 제출 현황표, 미제출자 필터링, 과제 엑셀(.xls) 저장 및 인쇄.

### 6. 📖 수업 진도 & 시간표 연동
- 오늘 수업 내용 및 다음 시간 연계/준비 사항 기록.
- 메인 대시보드 상단에 이전/오늘 진도 프리뷰 자동 표시, 진도 CSV 저장.
- 요일별 시간표 설정 후 **'현재 시간표 적용'** 버튼으로 현재 교시 반 좌석표 자동 표시.

### 7. ☁️ 구글 스프레드시트 & GitHub 클라우드 동기화 (Multi-Device Sync)
- **Google 스프레드시트 (Apps Script) 실시간 연동 (강력 추천)**:
  - 구글 시트의 Apps Script 웹 앱과 연동하여 학교 PC, 집 노트북, 스마트폰 어디서나 실시간 자동 저장 및 동기화.
  - 별도 토큰 발급 없이 URL 복사-붙여넣기만으로 간편 설정.
- **GitHub 클라우드 암호화 동기화**:
  - GitHub REST API를 통해 개인 저장소와 기기간 자동/수동 동기화 지원.
  - Web Crypto API (PBKDF2 + AES-GCM 256bit)를 이용한 학생 개인정보 클라이언트 암호화.
- **로컬 JSON 백업 & 복원**: 파일 형태의 안전한 전체 백업 지원.

## 🌐 웹에서 바로 사용하기 (GitHub Pages 설정 방법)
이 프로젝트는 웹상에서 바로 실행할 수 있도록 정적 페이지로 구성되어 있습니다.

1. 이 저장소의 **Settings** 탭으로 이동합니다.
2. 좌측 메뉴에서 **Pages**를 클릭합니다.
3. **Build and deployment** 섹션의 **Source**에서 `Deploy from a branch`를 선택합니다.
4. **Branch**를 `main` (혹은 `master`)으로 선택하고 폴더를 `/ (root)`로 설정한 뒤 **Save**를 누릅니다.
5. 몇 분 후 상단에 표시되는 URL(예: `https://edcom1004-hub.github.io/classroom_seating/`)로 접속하여 웹상에서 바로 사용하실 수 있습니다.
